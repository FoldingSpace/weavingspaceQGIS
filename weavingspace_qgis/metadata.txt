about=Creates tiled and woven map layers that carry several attributes
    of a polygon dataset in a single map, using the weavingspace library
    by David O'Sullivan and Luke Bergmann (bundled, MIT licensed).
    Choose a tiling or weave design, assign a variable and colour ramp
    to each pattern element, and the plugin adds a group of ordinary
    QGIS layers seeded with standard renderers, ready for the usual
    styling tools. The method is described in O'Sullivan and Bergmann
    (2026), Cartographic Perspectives 108. This is an experimental
    prototype, mostly co-written by Luke Bergmann with large language
    models. Requires QGIS 4 or later. It needs geopandas, pandas, and
    shapely, which most QGIS 4 installations already include; where
    they are missing or too old (most often on Linux, where QGIS uses
    the system Python), the plugin shows exactly what it would fetch
    and asks first; approving downloads those wheels from PyPI into
    the plugin's own folder, changing nothing else in your QGIS
    installation, and declining simply closes the plugin. Released
    under the MIT licence; the bundled weavingspace library is MIT
    too, and both notices are in LICENSE.md.

changelog=0.24.0 The map now follows the layer: editing, deleting or
    reprojecting features in QGIS updates it rather than leaving it
    out of date, and a column added there can be mapped straight
    away. Areas with no value are left out of the class breaks and
    counted in a notice; a column with one value draws as one class;
    choosing a quantitative style for a column of text draws
    categories rather than nothing. An Edit colours button sets a
    colour per value for categorical elements. Warnings when a spacing leaves areas off the
    map, when a changed category count moves existing colours, and
    when two elements' colours are hard to tell apart. The preview now
    shows one ring of neighbouring tiles by default, and colour-ramp
    swatches are larger.
    0.23.0 Reverse-ramp switches and per-element opacity in the
    data table; grid and stripe families with row and column controls;
    published as a public repository with a project page.
