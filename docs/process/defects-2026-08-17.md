# Every defect found on 2026-08-17, and what each one still owes

A LEDGER, not a narrative. It exists so that nothing found on this day
depends on anybody's memory or on a conversation surviving: each row
says what was wrong, where, when it arrived, how it was found, and
what it still owes. Read it beside ROADMAP.md, which carries only what
is OUTSTANDING; this file carries everything, closed included, because
"was that fixed?" is the question a ledger answers and a roadmap
cannot.

Twenty-six defects, four of them still OPEN. Fifteen were found by hunts aimed at code written
that day; **seven were older** -- 10 August, 14 August, 15 August and
v0.23.0 -- and surfaced only because a hunt was pointed at the new work
beside them. Several were inside FIXES for defects the same day's
earlier hunts had found.

**ALL OF THEM ARE IN THE PUBLISHED rc7** (`v0.24.3rc7`, tagged at
`1866338`), which is green on every local gate and on both CI jobs.
rc8 replaces it; rc7 must not be promoted or sent to a tester.

## How to read the columns

**Owes** is the honest state of the guard, and it is the point of the
file. `test + entry` means a regression test exists AND a mutation
catalogue entry was proved to catch its removal. `test` means the test
exists and the entry does not. `--` means neither, and the fix rests
on its hunt's reproduction alone, which is not what this project calls
fixed.

## Rows 30-33: what is known, and what was already tried

**30, the design view.** `_table_id_colours` asks only the ROW -- mode,
single colour, `ramp_swatch_colour(a["ramp"])` -- and has no deferring
branch, though `_ramp_cell_icon` grew one on 2026-08-15 for exactly
this reason. It also ignores `range_bounds`, though
`graduated_class_colours` already samples a windowed ramp. Probe:
`tools/probes/preview_paints_colours_the_map_does_not.py`. The second
arm (the display window) is a PREFERENCE rather than a defect if
"representative of the ramp" beats "representative of the window";
the first arm is not.

**31, the opacity, AND A FIX THAT DID NOT WORK.** Probe:
`tools/probes/opacity_lost_when_a_project_opens.py`. `_adopt_category_
colours` recovers `layer.opacity()` into `_opacity_choices`; the
Opacity cell is CREATED and never updated (`if row_id and
self._row_opacity(row) is None:`), `setRowCount` clears no cell
widgets, so an open dialog's spin survives and `_refresh_table` writes
the record back FROM it.
ATTEMPTED AND REVERTED, 2026-08-17: an `_adopting` flag set in
`_adopt_existing_group` and read in `_refresh_table`, plus a
record-wins branch in `_sync_row`. The probe was UNCHANGED by it --
C2 still read 100 over a layer drawn at 40 -- so the rebuild that
clobbers the record is not the one the flag guards, or does not run
between those two points. Do not repeat that shape without first
instrumenting WHICH rebuild writes the record, with a dump inside
`_refresh_table` behind an environment flag. The reverted attempt is
in this session's history and is not worth recovering.

**32, the Classes spinner.** Probe:
`tools/probes/pins_killed_by_the_class_count.py`, three parts.
`_retire_an_undrawable_pin`'s own comment says retirement is "for a
pin the DATA MOVED OUT FROM UNDER", and a class count is not that. Its
settled twin two lines away -- a copied ladder meeting a new class
count -- KEEPS the bounds, on the rule that "a pin is a smaller and
more durable statement than an imported ladder". Same handler,
opposite answers. `pin_problem` even has the right sentence and it is
never shown. NEEDS A RULING: whether a refused class count may destroy
pins at all, and if so why only this half.

**33, the constant-column notice.** `_legend_size_note` was
deliberately added to the restyle path so a class-count change is not
silent, and `few_values_message` returns None at `distinct <= 1` --
so the constant sentence, which is that rule's n=1 instance, was left
behind. Low harm: the user heard it once, on the first Generate.

## The four families

Each family was found by fixing ONE member and hunting the rest, and in
three of the four the second member was OLDER than the first.

**A guard in front of an exit about something else** (8, 14, 15, 18).
A colour comparison standing in front of the GeoPackage write, twice --
once graduated, once categorized, the second found only because the
first was fixed. An in-flight gate in front of the table learning what
the landing was about to ask it.

**A number printed in one notation and parsed in another** (13, 17,
26). Each printed a hard-coded full stop beside a widget that parses
through QLocale. The sweep that settles the family is not "which
strings hold numbers" but WHICH WIDGETS TAKE NUMBERS: there are two.

**A control that eats a keystroke** (1, 2, 12, 19, 27). A range
clamped to 100x the data; two boxes clamping each other; `decimals`
lowered to tidy a display; a `valueChanged` handler rewriting its own
box mid-edit. Every guard on every one drove `setValue` and passed.

**A widget written without the record behind it** (16, 24). The class
count written to the spinner and not `_class_counts`; the style combo
written twice without `touched`, once in the follow and once in the
deferral exit -- the first was fixed and the second never grepped for.

## Process changed the same day, and where it now lives

None of this is in this file; it is here as an index, because a
procedure recorded only in a session is a procedure that did not
happen.

- **Hunt a batch of new tests, per assertion** -- docs/TESTING.md,
  "THE TRIGGER". The catalogue proves a test's primary axis and
  structurally cannot see the rest.
- **When a fix and its test are in, re-hunt that ground** -- near the
  fix, not on it. docs/TESTING.md, "THE SECOND TRIGGER".
- **Test a control by typing into it, not by `setValue`** --
  docs/TESTING.md, with the character-by-character `validate` walk and
  when `QTest.keyClicks` is needed instead.
- **A guard that asks about one thing must not stand in front of an
  exit about another** -- CLAUDE.md.
- **A refresh with one caller is a refresh that only works once** --
  CLAUDE.md. Grep the constructor as well as the updater.
- **When a fix is written into two paths in one commit, diff the two
  hunks against each other** -- CLAUDE.md. And: one dedup set must not
  gate two different things.
- **A guard that runs before a re-read must be asked with re-read
  values too** -- CLAUDE.md.
- **The plugin's table follows the layer's renderer**, and the scope
  of that -- CLAUDE.md, with the maintainer's ruling.
