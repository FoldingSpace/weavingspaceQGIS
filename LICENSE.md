## Test data

`tests/data/imd-auckland-sa2-2018.gpkg` holds Index of Multiple
Deprivation scores for Auckland statistical area 2 units, 2018, as
distributed with the weavingspace library's own examples. The maps
shown in the README and on the project page are drawn from it.
